# OwnReel

从灵感到可编辑成片：在自己的主机运行一体化创作、智能成片、资产库和多轨剪辑器。默认英文，可切换中文。不需要 FlowBar 主站账号、订阅、积分钱包或线上审核服务。

> V0.1.0 为面向单个本地所有者的早期社区版。安装前请查看 [验收范围与限制](VERIFICATION.md) 和仓库最新 Actions 状态，不应直接作为公网多租户服务部署。

## 安装

准备 Docker + Compose v2、Node.js 22+。建议 4 核 CPU、8GB 内存、10GB 可用磁盘。渲染无需本地 GPU，生成模型在供应商端运行。

在仓库根目录执行：

```sh
node scripts/community-init.mjs
docker compose --env-file .env -f deploy/community/compose.yaml up --build -d
docker compose --env-file .env -f deploy/community/compose.yaml exec api cat /data/bootstrap-token
```

打开 `http://localhost:4420`，使用一次性初始化令牌创建本地账户（密码至少 12 位），再登录。令牌 30 分钟有效，未完成初始化时重启 API 可重新签发。不要公开令牌。

默认只监听 127.0.0.1，不接公网。远程服务器使用 SSH 隧道访问。社区版首版面向单个本地所有者，不应直接改成开放注册的多人公网服务。

## 不配密钥也能出片

没有测试素材时，先执行 `npm ci --ignore-scripts`，再运行 `node scripts/create-samples.mjs`，会在 `data/samples` 生成原创几何产品图、简单合成音轨和中英字幕/配音文本。示例明确标记为非 AI 素材；真人配音可自行录制，或选择可选的付费 TTS。

1. **项目**：创建项目。
2. **资产库**：上传自己的图片、视频、音频，每个文件最多 100MB。
3. **智能成片**：选择产品广告、功能介绍或社交短视频模板，点击“使用手工模板（非 AI）”；逐镜头选择素材、字幕、时长，保存分镜。
4. 点击“创建可编辑时间线”，在新标签页打开剪辑器，添加音乐、裁剪拆分、调整音量和转场。
5. 本地导出 H.264/AAC MP4，支持 720p/1080p、横屏/竖屏。导出结果自动入库。

## 使用 AI

在**设置**保存自己的 fal 密钥，支持脚本、图片、文生/图生视频、中英配音。模型费用由 fal 直接收取，生成前必须确认。未知价格不表示免费，重试可能再次收费。查看供应商最新报价与余额后再提交。

**一体化创作**：生图 → 使用资产做图生视频 → 加入当前项目 → 进入剪辑器 → 导出，不需要下载再上传。

**智能成片**：生成脚本 → 修改分镜 → 逐镜头生成或选择画面、配音 → 使用结果 → 保存 → 建立时间线 → 编辑导出。失败镜头可单独重新生成，不重跑其他镜头。配音太长时可延长图片镜头，或缩短配音/换更长视频，不会静默截断。

## 保存与恢复

关闭页面不会停止主机任务。项目和资产保存在本机；删除项目保留素材，被项目引用的素材禁止删除。多标签版本冲突会明确报错，避免静默覆盖。

“提交结果未知”时先查 fal 请求历史，再用已有请求 ID 恢复查询；不要直接重发。恢复下载不产生新的生成请求。上游已执行的任务不承诺取消或退款。

请同时备份数据库、媒体卷与加密主密钥。完整启动、备份、恢复、升级、卸载说明见 [运维指南](OPERATIONS.md)。不要使用全局清理命令，不要删除未验证备份的数据卷。
